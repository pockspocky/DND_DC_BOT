# DND_DC_BOT - 龙与地下城Discord机器人

![Status](https://img.shields.io/badge/状态-正常运行-brightgreen) ![Version](https://img.shields.io/badge/版本-v1.0-blue) ![Commands](https://img.shields.io/badge/斜杠命令-10个-orange) ![Tests](https://img.shields.io/badge/测试-通过-success)

一个专为龙与地下城(D&D)游戏设计的Discord机器人，旨在为玩家和DM提供便捷的游戏辅助功能。

## 🚀 快速开始

机器人已完成核心骰子系统开发，支持完整的D&D投掷功能：
- ✅ **基础投掷**: `/roll dice:d20`
- ✅ **优势/劣势**: `/roll dice:d20 advantage:优势 modifier:5`
- ✅ **复杂投掷**: `/roll dice:d6 count:4 drop_lowest:1`
- ✅ **技能检定**: `/check modifier:5 advantage:优势`
- ✅ **属性生成**: `/stats method:4d6去最低`

## 🎲 `/roll` 命令使用指南

### 基础用法
```
/roll dice:d20                          # 投掷1个d20
/roll dice:d6                           # 投掷1个d6
/roll dice:d100                         # 投掷1个d100
```

### 带修正值
```
/roll dice:d20 modifier:5               # 投掷d20+5
/roll dice:d8 modifier:-2               # 投掷d8-2
```

### 优势/劣势投掷
```
/roll dice:d20 advantage:优势           # 优势骰 (2d20取高)
/roll dice:d20 advantage:劣势           # 劣势骰 (2d20取低)
/roll dice:d20 advantage:优势 modifier:3 # 优势骰+3
```

### 多个骰子
```
/roll dice:d6 count:3                   # 投掷3d6
/roll dice:d8 count:2 modifier:4        # 投掷2d8+4
```

### 保留/丢弃规则
```
/roll dice:d6 count:4 drop_lowest:1     # 4d6去最低 (D&D属性生成)
/roll dice:d20 count:2 keep_highest:1   # 2d20保留最高
/roll dice:d12 count:5 keep_highest:3 modifier:-1  # 5d12保留最高3个-1
```

### 复杂组合示例
```
/roll dice:d8 count:3 modifier:2 private:true      # 3d8+2 (私密显示)
/roll dice:d6 advantage:优势 modifier:4             # d6优势骰+4
```

## 📋 命令参考

### 基础命令
- `/roll` - 投掷骰子 (支持多种参数组合)
  - `dice`: 基础骰子 (如: d20, d6, d100)
  - `modifier`: 修正值 (可选)
  - `advantage`: 优势/劣势/正常 (可选)
  - `count`: 骰子数量 (可选)
  - `keep_highest`: 保留最高几个 (可选)
  - `drop_lowest`: 丢弃最低几个 (可选)
  - `private`: 是否私密显示 (可选)
- `/check <修正值>` - 技能检定
- `/save <豁免类型> <修正值>` - 豁免投掷
- `/attack <攻击加值> <伤害骰>` - 攻击检定
- `/stats <方法>` - 生成角色属性
- `/rollhelp` - 显示详细的骰子帮助

### 角色管理
- `/character create` - 创建新角色
- `/character show` - 显示角色信息
- `/character edit <属性>` - 编辑角色属性
- `/hp <+-数值>` - 修改生命值

### 战斗系统
- `/initiative` - 开始先攻投掷
- `/combat start` - 开始战斗
- `/combat next` - 下一个回合
- `/combat end` - 结束战斗

### 查询功能
- `/spell <法术名>` - 查询法术
- `/monster <怪物名>` - 查询怪物
- `/item <物品名>` - 查询物品
- `/rule <规则>` - 查询规则

### DM工具
- `/generate npc` - 生成随机NPC
- `/generate treasure` - 生成随机宝藏
- `/weather` - 随机天气
- `/xp <数值>` - 分配经验值

## 🚀 安装和配置

1. 克隆项目到本地
```bash
git clone https://github.com/yourusername/DND_DC_BOT.git
cd DND_DC_BOT
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 配置环境变量
创建 `.env` 文件并添加：
```
DISCORD_TOKEN=your_discord_bot_token
PREFIX=/
```

4. 运行机器人
```bash
python main.py
```
