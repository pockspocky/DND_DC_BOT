# ⚔️ DND Discord Bot 战斗管理系统指南

## 📖 概述

战斗管理系统是DND Discord Bot的核心功能之一，为D&D 5e游戏提供完整的战斗辅助工具。系统支持回合制战斗、先攻管理、生命值追踪、伤害计算等功能。

## 🎯 主要功能

### 🔥 战斗会话管理
- 创建和结束战斗会话
- 支持多频道独立战斗
- 自动生成战斗名称和ID

### 👥 参与者管理
- 添加和移除战斗参与者
- 支持玩家角色和NPC
- 自动先攻排序

### 🔄 回合系统
- 基于先攻值的回合顺序
- 自动回合切换
- 回合计数器

### 💥 伤害和治疗
- 支持骰子表达式伤害
- 实时生命值更新
- 治疗效果计算

### 📊 状态显示
- 美观的战斗状态展示
- 生命值条可视化
- 回合指示器

## 🎮 命令详解

### 基础战斗命令

#### `/cs [name]` - 开始新战斗
**描述**: 在当前频道开始一个新的战斗会话
**参数**:
- `name` (可选): 战斗名称，不填写会自动生成

**示例**:
```
/cs 龙巢入侵战
/cs
```

**权限**: 需要DM角色或管理员权限

---

#### `/ce` - 结束当前战斗
**描述**: 结束当前频道的活跃战斗
**示例**:
```
/ce
```

**权限**: 需要DM角色或管理员权限

---

#### `/st` - 查看战斗状态
**描述**: 显示当前战斗的详细状态信息
**示例**:
```
/st
```

**权限**: 所有用户可用

---

### 参与者管理命令

#### `/add <name> <max_hp> <initiative> [ac] [is_npc]` - 添加参与者
**描述**: 向当前战斗添加新的参与者
**参数**:
- `name`: 角色名称（必须）
- `max_hp`: 最大生命值（必须）
- `initiative`: 先攻值（必须）
- `ac`: 护甲等级（可选，默认10）
- `is_npc`: 是否为NPC（可选，默认False）

**示例**:
```
/add 阿拉贡 45 16 18
/add 哥布林 7 12 15 true
```

**权限**: 需要DM角色或管理员权限

---

#### `/rm <name>` - 移除参与者
**描述**: 从当前战斗中移除指定参与者
**参数**:
- `name`: 要移除的角色名称

**示例**:
```
/rm 哥布林
```

**权限**: 需要DM角色或管理员权限

---

### 回合管理命令

#### `/next` - 下一个回合
**描述**: 切换到下一个角色的回合
**示例**:
```
/next
```

**权限**: 需要DM角色或管理员权限

---

### 生命值管理命令

#### `/dmg <target> <expression> [attacker]` - 造成伤害
**描述**: 对指定目标造成伤害
**参数**:
- `target`: 目标角色名称（必须）
- `expression`: 伤害表达式或固定数值（必须）
- `attacker`: 攻击者名称（可选）

**支持的伤害表达式**:
- 固定数值: `8`, `15`, `23`
- 骰子表达式: `1d8+3`, `2d6`, `1d12+5`

**示例**:
```
/dmg 哥布林 8
/dmg 阿拉贡 2d6+3 兽人酋长
/dmg 法师 1d8+2
```

**权限**: 需要DM角色或管理员权限

---

#### `/heal <target> <expression> [healer]` - 治疗角色
**描述**: 治疗指定角色
**参数**:
- `target`: 目标角色名称（必须）
- `expression`: 治疗表达式或固定数值（必须）
- `healer`: 治疗者名称（可选）

**支持的治疗表达式**:
- 固定数值: `8`, `15`, `23`
- 骰子表达式: `1d8+3`, `2d4+2`, `1d6+4`

**示例**:
```
/heal 阿拉贡 8
/heal 法师 1d8+3 牧师
/heal 游侠 2d4+2
```

**权限**: 需要DM角色或管理员权限

## 🎯 使用流程示例

### 典型战斗流程

1. **开始战斗**
   ```
   /cs 哥布林伏击战
   ```

2. **添加参与者**
   ```
   /add 战士 45 16 18
   /add 法师 25 14 12
   /add 游侠 35 15 14
   /add 哥布林1 7 12 15 true
   /add 哥布林2 7 10 15 true
   ```

3. **查看战斗状态**
   ```
   /st
   ```

4. **进行战斗回合**
   ```
   /dmg 哥布林1 1d8+3 战士
   /next
   /heal 战士 1d8+2 法师
   /next
   ```

5. **结束战斗**
   ```
   /ce
   ```

## 🔧 权限系统

### DM权限检查
系统会自动检查用户是否具有以下权限之一：
- 拥有名为"DM"、"dm"、"Dm"或"dM"的角色
- 拥有服务器管理员权限

### 命令权限分类
- **查看命令**: `/st` - 所有用户可用
- **管理命令**: 其他所有命令 - 仅DM可用

## 📊 功能特性

### 先攻排序
- 自动按先攻值从高到低排序
- 支持相同先攻值的处理
- 动态重排序

### 生命值可视化
系统使用进度条显示生命值状态：
- 🟢 75-100% 健康
- 🟡 25-74% 受伤
- 🔴 1-24% 重伤
- 💀 0% 死亡/无意识

### 角色类型标识
- 🎭 玩家角色
- 🤖 NPC

### 回合指示器
- 👈 当前回合角色
- 　 等待回合角色

## 🚀 高级功能

### 骰子集成
战斗系统完全集成了机器人的骰子系统：
- 支持标准D&D骰子表达式
- 自动计算修正值
- 显示骰子结果详情

### 数据持久化
- 战斗数据自动保存到数据库
- 支持机器人重启后恢复
- 完整的战斗日志记录

### 多频道支持
- 每个频道独立的战斗会话
- 不同频道可同时进行多场战斗
- 频道隔离的参与者管理

## ⚠️ 注意事项

1. **唯一性约束**: 每个战斗中角色名称必须唯一
2. **数值限制**: 生命值、先攻值等必须为正整数
3. **权限要求**: 管理命令需要DM权限
4. **频道限制**: 每个频道同时只能有一个活跃战斗

## 🆘 常见问题

### Q: 如何成为DM？
A: 需要服务器管理员给您分配名为"DM"的角色，或者您拥有管理员权限。

### Q: 战斗数据会丢失吗？
A: 不会，所有战斗数据都保存在数据库中，机器人重启不会影响正在进行的战斗。

### Q: 可以同时进行多场战斗吗？
A: 可以，不同频道可以同时进行独立的战斗。

### Q: 骰子表达式有什么限制？
A: 支持标准D&D表达式，如1d20+5、2d6等，具体限制请参考骰子系统文档。
