# D&D查询功能使用指南

## 🎯 概述

DND_DC_BOT现在支持通过Discord斜杠命令查询D&D 5e的法术、怪物和技能信息！所有数据来自官方的D&D 5e系统参考文档(SRD)。

## 📋 可用命令

### `/spell <法术名>`
查询D&D 5e法术的详细信息。

**示例用法**:
- `/spell fireball` - 查询火球术
- `/spell magic missile` - 查询魔法飞弹  
- `/spell cure wounds` - 查询治疗轻伤

**显示信息**:
- 法术等级和学派
- 施法时间、射程、持续时间
- 成分要求（语言、姿势、材料）
- 伤害信息（如果适用）
- 豁免检定和影响区域
- 可使用的职业
- 高环施法效果

### `/monster <怪物名>`
查询怪物的属性和战斗数据。

**示例用法**:
- `/monster goblin` - 查询哥布林
- `/monster orc` - 查询兽人
- `/monster adult-black-dragon` - 查询成年黑龙

**显示信息**:
- **基本信息**：AC、HP、先攻、CR、XP
- **属性值**：STR、DEX、CON、INT、WIS、CHA（包含修正值）
- **移动速度**：各种移动方式和速度
- **豁免检定**：各项豁免检定的加值
- **技能**：熟练技能及其加值
- **抗性/免疫**：伤害抗性、免疫、弱点、状态免疫
- **感官**：特殊感官能力和被动察觉
- **语言**：该怪物掌握的语言
- **特殊能力**：种族特性和特殊能力
- **攻击动作**：所有攻击方式和伤害
- **传奇动作**：高级怪物的传奇动作（如果有）
- **反应动作**：反应性攻击和防御（如果有）

**智能Thread展示**:
- 当怪物信息过长（超过750字符）时，会自动创建Thread详细展开
- 主消息显示核心数据，Thread中按类别分组显示完整信息
- 高级怪物（如成年黑龙）会触发Thread展示，提供最佳阅读体验

### `/skill <技能名>`
查询技能的详细说明和关联属性。

**示例用法**:
- `/skill perception` - 查询察觉
- `/skill stealth` - 查询潜行
- `/skill investigation` - 查询调查

**显示信息**:
- 技能详细描述
- 关联的属性值
- 使用场景说明

## 💡 使用技巧

### 1. 英文名称
所有查询都需要使用**英文名称**，因为数据来源于英文的SRD文档。

### 2. 常见法术名称
- `fireball` - 火球术
- `magic-missile` - 魔法飞弹
- `cure-wounds` - 治疗轻伤
- `healing-word` - 治疗之语
- `shield` - 护盾术
- `mage-armor` - 法师护甲

### 3. 常见怪物名称
- `goblin` - 哥布林
- `orc` - 兽人
- `skeleton` - 骷髅
- `zombie` - 僵尸
- `adult-black-dragon` - 成年黑龙
- `owlbear` - 枭熊

### 4. 常见技能名称
- `perception` - 察觉
- `stealth` - 潜行
- `investigation` - 调查
- `insight` - 洞察
- `persuasion` - 说服
- `deception` - 欺骗

### 5. 名称格式
- 多个单词用连字符连接：`magic-missile`, `cure-wounds`
- 复合名称要完整：`adult-black-dragon` 而不是 `dragon`
- 如果不确定确切名称，可以尝试相近的词
